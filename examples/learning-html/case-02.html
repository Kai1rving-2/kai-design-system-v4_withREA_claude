从上到下：应用层 → 传输层 → 网络层 → 链路层。
02 / 两种视角

逻辑上对话，实际上逐层传递。

同层两端遵循相同协议，称为逻辑上的 peer（对等实体）；这不是说 HTTP 数据会跳过下面三层直接飞到对端。

真正的路径：发送端的数据逐层向下封装，经物理网络和可能的中间设备传输；接收侧逐层解封装，再交给相应的上层。* 802.11 只是讲义中发送端无线接入的链路层示例，并非所有设备、每一跳或接收端都必须使用 802.11。

# Icon

Use the built-in line icons as small cues beside a clear text label. They use `currentColor`, a rounded 1.75px stroke and an 18px default size. Do not use an icon to replace essential text. In an icon-only `IconButton`, always provide a specific `aria-label`; the same label appears as a visual tooltip on hover and keyboard focus. Decorative icons are hidden from assistive technology by default. Use `spark` sparingly for a true KAI signature moment, never as a default action marker.
